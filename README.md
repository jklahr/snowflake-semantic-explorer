# Snowflake Semantic Explorer: plugin marketplace

Plugins for exploring and analyzing Snowflake data through governed definitions.

| Plugin | What it is |
|---|---|
| `snowflake-semantic-explorer` | **Install this.** Explore, analyze, build interactive dashboards, run deep dives. Needs a Snowflake MCP server connected to Claude. |
| `snowflake-semantic-explorer-dashboards` | Optional add-on for live dashboards. Needs an administrator to deploy a server first. |

**Claude Code**

    /plugin marketplace add <owner>/<this-repo>
    /plugin install snowflake-semantic-explorer@snowflake-semantic-explorer-marketplace

**claude.ai and Cowork (Team and Enterprise):** an organization owner adds this repository under Organization settings > Plugins.
